# คู่มือใช้งาน Shopee Auto สำหรับมือใหม่

โปรเจกต์นี้ช่วยทำวิดีโอโปรโมทสินค้า Shopee แบบอัตโนมัติ (ดึงสินค้า → ดาวน์โหลดภาพ →
ตัดต่อวิดีโอ → ให้คุณตรวจก่อนโพสต์) ตอนนี้มี **หน้าเว็บแดชบอร์ด** (`app.py`) ให้กดใช้งาน
ผ่านเบราว์เซอร์ ไม่ต้องพิมพ์คำสั่งเยอะ

## ภาพรวมขั้นตอนทำงาน

```
① ดึงสินค้าจาก Shopee  →  ② ดาวน์โหลดภาพ + ตัดวิดีโอ  →  ③ คุณตรวจและกด "อนุมัติ"  →  ④ โพสต์จริง (TikTok/YouTube)
```

ระบบออกแบบให้ **คนตรวจก่อนโพสต์เสมอ** (human-in-the-loop) จะไม่มีการโพสต์อัตโนมัติ
โดยไม่มีใครกดอนุมัติก่อน

---

## ขั้นที่ 1: เตรียมเครื่องคอมพิวเตอร์ (ทำครั้งเดียว)

ต้องมีโปรแกรมเหล่านี้ก่อน:

1. **Python 3.11 ขึ้นไป** — ดาวน์โหลดที่ https://www.python.org/downloads/
   (ตอนติดตั้งบน Windows ให้ติ๊ก "Add Python to PATH" ด้วย)
2. **ffmpeg** (โปรแกรมตัดต่อวิดีโอเบื้องหลัง)
   - Windows: ดาวน์โหลดจาก https://ffmpeg.org/download.html แล้วเพิ่มลง PATH
   - Mac: เปิด Terminal พิมพ์ `brew install ffmpeg`
   - Linux: พิมพ์ `sudo apt install ffmpeg`
3. **ฟอนต์ไทย** — ใส่ไฟล์ **Noto Sans Thai** ไว้ให้แล้วในโฟลเดอร์ `assets/fonts/`
   (`NotoSansThai-Regular.ttf` และ `NotoSansThai-Bold.ttf`) ไม่ต้องดาวน์โหลดเพิ่มเอง
   ถ้าอยากเปลี่ยนฟอนต์ ก็แค่แทนที่ไฟล์สองไฟล์นี้ด้วยฟอนต์ไทยอื่นที่ชื่อไฟล์เดียวกัน

---

## ขั้นที่ 2: ติดตั้งโปรเจกต์ (ทำครั้งเดียว)

เปิด Terminal (Mac/Linux) หรือ Command Prompt/PowerShell (Windows) แล้วเข้าไปในโฟลเดอร์
โปรเจกต์ที่แตกไฟล์ zip ออกมา จากนั้นพิมพ์ทีละบรรทัด:

```bash
cd shopee-auto
pip install -r requirements.txt
```

รอจนติดตั้งเสร็จ (อาจใช้เวลาสักครู่ครั้งแรก)

---

## ขั้นที่ 3: กรอกข้อมูลบัญชี (สำคัญมาก)

1. คัดลอกไฟล์ `.env.example` แล้วเปลี่ยนชื่อเป็น `.env`
2. เปิดไฟล์ `.env` ด้วยโปรแกรมแก้ไขข้อความ (Notepad ก็ได้) แล้วกรอก:
   - `SHOPEE_APP_ID` และ `SHOPEE_APP_SECRET` — ขอได้ที่ https://affiliate.shopee.co.th/open_api
   - `IMAGE_ALLOWED_HOSTS` — ชื่อโฮสต์ของภาพสินค้าที่ยืนยันแล้วจาก API (ระบบไม่ยอมดาวน์โหลด
     ภาพจากที่อื่นเพื่อความปลอดภัย) เช่น `down-th.img.susercontent.com` — ควรตรวจสอบจาก
     response จริงของ API ก่อน ห้ามเดา
   - ถ้าจะโพสต์ TikTok/YouTube จริง ต้องกรอกช่อง TikTok/Google เพิ่มด้วย (ขั้นตอนนี้ซับซ้อน
     กว่าปกติ แนะนำให้ทดสอบขั้นตอนอื่นให้เสร็จก่อน)

⚠️ **ห้ามส่งไฟล์ `.env` ให้ใคร หรือแปะเข้าไปในแชต** เพราะมีรหัสลับของบัญชีคุณอยู่ข้างใน

---

## ขั้นที่ 4: เปิดแดชบอร์ด

ในโฟลเดอร์โปรเจกต์ (`shopee-auto`) พิมพ์:

```bash
python app.py
```

จะเห็นข้อความว่า `เปิดเบราว์เซอร์ไปที่ http://127.0.0.1:5000`
ให้เปิดเบราว์เซอร์ (Chrome/Edge/Safari) แล้วพิมพ์ที่อยู่นี้ในแถบ URL:

```
http://127.0.0.1:5000
```

จะเห็นหน้าแดชบอร์ดสีส้มของ Shopee 🛒

**หมายเหตุ:** หน้าเว็บนี้รันอยู่ในเครื่องคุณเองเท่านั้น ไม่มีใครจากภายนอกเข้าถึงได้
ถ้าจะปิดโปรแกรม ให้กลับไปที่ Terminal แล้วกด `Ctrl + C`

---

## ขั้นที่ 5: ใช้งานหน้าแดชบอร์ด

### หน้า "ตั้งค่า"
เข้าไปดูก่อนเป็นอันดับแรก จะมีเครื่องหมาย ✅/❌ บอกว่าตั้งค่าอะไรครบหรือยังครบ
(Shopee API, ฟอนต์ไทย, ffmpeg ฯลฯ)

### หน้า "หน้าหลัก"
กดปุ่มตามลำดับ:
1. **① ดึงสินค้าจาก Shopee** — ระบบจะไปดึงรายการสินค้าล่าสุดจากบัญชี affiliate ของคุณ
2. **② ดาวน์โหลดภาพ + ตัดวิดีโอ** — ระบบจะดาวน์โหลดรูปสินค้า แล้วตัดต่อเป็นวิดีโอแนวตั้ง
   (สำหรับ TikTok/YouTube Shorts) อัตโนมัติ อาจใช้เวลาสักพักถ้ามีสินค้าหลายชิ้น

ถ้ามีอะไรผิดพลาด (เช่น ยังไม่ได้กรอก API key) จะมีข้อความสีแดงอธิบายสาเหตุแบบอ่านง่าย
ขึ้นด้านบนของหน้า

### หน้า "สินค้า"
ดูรายชื่อสินค้าทั้งหมด พร้อมสถานะ (ใหม่ / พร้อมตัด / ตัดวิดีโอแล้ว / ดาวน์โหลดภาพไม่สำเร็จ)
ถ้าตัดวิดีโอเสร็จแล้ว จะมีวิดีโอให้กดดูตัวอย่างในตารางเลย — **ดูให้แน่ใจว่าวิดีโอโอเคก่อน**
ค่อยไปกดอนุมัติที่หน้าถัดไป

### หน้า "รออนุมัติ"
นี่คือขั้นตอนสำคัญที่สุด — ทุกวิดีโอต้องผ่านการตรวจสอบของคุณก่อนโพสต์จริงเสมอ
- ตารางบนสุด: รายการที่รอคุณตรวจ กดปุ่ม **"อนุมัติ"** เมื่อดูวิดีโอแล้วโอเค
- ตารางล่าง: รายการที่อนุมัติแล้ว พร้อมโพสต์จริง กดปุ่ม **"โพสต์รายการที่อนุมัติแล้วทั้งหมด"**
  เมื่อพร้อม (ต้องกรอก TikTok/YouTube API ให้ครบก่อน ไม่งั้นจะขึ้นข้อความผิดพลาด)

---

## สรุปสั้นๆ ทุกครั้งที่จะใช้งาน

```bash
cd shopee-auto
python app.py
```

แล้วเปิด http://127.0.0.1:5000 → กดปุ่มตามลำดับในหน้าหลัก → ตรวจวิดีโอที่หน้า "สินค้า"
→ อนุมัติที่หน้า "รออนุมัติ" → โพสต์เมื่อพร้อม

## ถ้าติดปัญหา

- หน้าเว็บขึ้นข้อความสีแดง → อ่านข้อความนั้น มักจะบอกตรงๆ ว่าไฟล์ `.env` ขาดอะไร
- วิดีโอมีตัวหนังสือเป็นกล่องสี่เหลี่ยม → เช็คว่าไฟล์ฟอนต์ในโฟลเดอร์ `assets/fonts/` ยังอยู่ครบหรือไม่
- ปุ่มดาวน์โหลดภาพไม่ทำงาน → ตรวจ `IMAGE_ALLOWED_HOSTS` ในไฟล์ `.env` ว่าใส่ชื่อโฮสต์
  ถูกต้องหรือยัง (ต้องเป็นชื่อจริงจาก API response ห้ามเดา)
- ยังโพสต์ TikTok/YouTube จริงไม่ได้ → ส่วนนี้ต้องเชื่อมต่อบัญชีแยกต่างหาก (OAuth) ซึ่งซับซ้อน
  กว่าขั้นตอนอื่น แนะนำให้ทำขั้นตอนดึงสินค้า/ตัดวิดีโอ/อนุมัติให้คล่องก่อน
