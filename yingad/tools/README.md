# เครื่องมือยิงแอด

- `studio/` สตูดิโอบนเว็บ เลือกสินค้า ได้แคปชัน 4 แพลตฟอร์มและไฟล์คลิปแนวตั้ง พร้อมคิวโพสต์ 3 วันและตัวนับรายได้
- `products.json` รายการสินค้าที่ใช้ร่วมกันทั้งหน้าเว็บและสคริปต์ แก้ที่นี่ที่เดียว
- `tools/daily_pack.py` สร้างชุดคอนเทนต์รายวัน (คลิป 15 วินาที + แคปชัน) ระบบรายวันอ่านสินค้าจากฐานข้อมูล Notion "สินค้ายิงแอด" สินค้าที่ขายได้จะถูกเลือกถี่ขึ้น และมุมคลิปเปลี่ยนทุกวัน

```
python3 tools/daily_pack.py                 # ของวันนี้
python3 tools/daily_pack.py 2026-10-07      # ของวันที่กำหนด
python3 tools/daily_pack.py --input สินค้า.json  # ใช้รายการจาก Notion
```
ต้องมี Python, Pillow, ffmpeg และฟอนต์ Loma
